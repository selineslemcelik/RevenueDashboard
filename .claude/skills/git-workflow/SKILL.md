# Git kuralları

- Bu projede Git henüz kurulu değil (git init yapılmadı, uzak/remote yok).
- AI, git komutlarını KENDİSİ çalıştırmaz: git init, git add, git commit,
  git push, git pull, branch veya PR işlemleri dahil.
- Bu komutları yalnızca kullanıcı, kendi kararıyla çalıştırır.
- AI en fazla önerebilir: "şu git komutunu çalıştırabilirsin" der,
  ama komutu kendisi yürütmez.
- Git kurulduktan sonra bu dosya gerçek iş akışına göre (branch isimleri,
  commit mesaj formatı, PR kuralları) güncellenecektir.
