# Revenue Dashboard

An interactive revenue monitoring and analysis dashboard developed during my Software Engineering internship at Merzigo.

## Overview

Revenue Dashboard is designed to help company managers monitor and analyze revenue data through a single, easy-to-use interface.

The dashboard is designed for continuous display on a TV screen. Different dashboard views automatically switch every 30 seconds, allowing key metrics and analysis results to be monitored continuously.

## Features

- KPI and total revenue monitoring
- Daily, weekly, monthly and yearly revenue analysis
- Short-term and long-term dashboard views
- Automatic screen switching every 30 seconds
- Interactive revenue charts and data visualizations
- Company, platform and country-based data analysis
- Excel-based bulk data import
- User registration and login
- Data validation and data integrity controls

## Technologies

- C#
- ASP.NET Core MVC
- PostgreSQL
- SQL
- HTML / CSS
- JavaScript
- Chart.js
- ClosedXML
- Globe.gl

## Project Structure

The project follows a layered architecture:

- `Controllers` – Handles user requests and application flow
- `Services` – Contains business logic
- `Repositories` – Handles database operations
- `Models` – Contains application data models
- `Views` – Contains the user interface
- `Infrastructure` – Contains database and infrastructure components
- `wwwroot` – Contains static files such as CSS and JavaScript
